## 📖 About This Repository

This repository documents my **100 Days of Python** journey, where I commit to coding, learning, and building projects every day.

The goal is to improve my Python programming skills through consistent practice, problem-solving, and project development.

Throughout this challenge, I will explore:

- 🌐 APIs & Web Development

- 🎮 Mini Projects
- 🔥 Real-World Applications
